Spec-Generator: Ponto → Medicina Ocupacional (SST)

> Nexus > Especificação Técnica

1. Objetivo da Spec

Automatizar a convocação de Exame de Retorno ao Trabalho (NR-7) e o registro de Afastamentos (eSocial S-2230) a partir de atestados lançados no Ponto.

2. API Spec: Integração Ponto ↔ Medicina (Pronto para Vibecode)

{
  "openapi": "3.0.0",
  "info": {
    "title": "API de Gestão de Afastamentos e Retorno ao Trabalho",
    "version": "1.0.0",
    "description": "Automatização de gatilhos de SST baseados em registros de Ponto Eletrônico."
  },
  "paths": {
    "/atestados/registrar": {
      "post": {
        "summary": "Recebe o atestado do Ponto e dispara lógica de SST",
        "requestBody": {
          "content": {
            "application/json": {
              "schema": {
                "$ref": "#/components/schemas/AtestadoInput"
              }
            }
          }
        },
        "responses": {
          "201": {
            "description": "Gatilhos de conformidade processados com sucesso."
          }
        }
      }
    }
  },
  "components": {
    "schemas": {
      "AtestadoInput": {
        "type": "object",
        "properties": {
          "funcionario_id": { "type": "string", "format": "uuid" },
          "data_inicio": { "type": "string", "format": "date" },
          "dias_afastamento": { "type": "integer", "example": 32 },
          "cid": { "type": "string", "example": "M54.5" }
        },
        "required": ["funcionario_id", "data_inicio", "dias_afastamento"]
      }
    },
    "x-vibecode-logic": {
      "triggers": [
        {
          "condition": "dias_afastamento >= 30",
          "action": "CREATE_SST_EVENT",
          "params": {
            "tipo": "EXAME_RETORNO_TRABALHO",
            "prazo": "data_inicio + dias_afastamento",
            "notificar": ["Medico_Trabalho", "Gestor_RH"]
          }
        },
        {
          "condition": "dias_afastamento > 0",
          "action": "SYNC_ESOCIAL_S2230",
          "params": { "status": "RASCUNHO_PENDENTE" }
        }
      ]
    }
  }
}

4. Fluxo de IA (Interface de Demanda)

  1. Agente de Validação: Recebe a foto do atestado/input do RH.
  2. OCR & Analisador: Extrai datas e CID.
  3. Sugestor de Spec: Se o usuário pedir "quero que avise o médico", a IA gera o código: Notify(medico_trabalho, "Novo afastamento > 30 dias").
